## Problem Statement

Given an array of integers `nums` and an integer `target`, return indices of the two numbers such that they add up to `target`.

You may assume that each input would have exactly one solution, and you may not use the same element twice.

## Approach

We can solve this problem efficiently using a hash table (dictionary) to store the numbers we've seen so far and their indices.

### Algorithm

1. Create an empty hash table
2. Iterate through the array
3. For each element, calculate the complement (target - current element)
4. If the complement exists in the hash table, we found our answer
5. Otherwise, add the current element and its index to the hash table

### Time Complexity
- **Time**: O(n) - We traverse the list only once
- **Space**: O(n) - Hash table stores at most n elements

## Solution

```python
def twoSum(nums: list[int], target: int) -> list[int]:
    seen = {}

    for i, num in enumerate(nums):
        complement = target - num

        if complement in seen:
            return [seen[complement], i]

        seen[num] = i

    return []  # No solution found
```

### Example Walkthrough

```python
nums = [2, 7, 11, 15]
target = 9

# Iteration 1: i=0, num=2
# complement = 9 - 2 = 7
# 7 not in seen, add: seen = {2: 0}

# Iteration 2: i=1, num=7
# complement = 9 - 7 = 2
# 2 is in seen! Return [0, 1]
```

## Alternative Approaches

### Brute Force
Check every pair of numbers - O(n²) time complexity.

### Two Pointers
Only works if the array is sorted. Would require sorting first - O(n log n) time complexity.

## Key Takeaways

- Hash tables are excellent for lookup-heavy problems
- Trading space for time can dramatically improve performance
- Always consider what data structure fits your access pattern
